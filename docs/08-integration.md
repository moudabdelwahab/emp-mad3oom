# التكامل مع منصة مدعوم

## المبدأ

منصة مدعوم **لا تُعدَّل**. يُضاف إليها ملف واحد مستقل، ولا يُنقل أي كود من
مدعوم إلى هذا المستودع ولا العكس.

```
منصة مدعوم (مستودعها)
      │  import { Mad3oomActivity } from './mad3oom-activity-client.js'
      ▼
Employee Activity SDK   (ملف واحد، بلا اعتماديات)
      │  supabase.rpc('eo_ingest_activity', …)   بجلسة الموظف نفسها
      ▼
public.eo_ingest_activity   [SECURITY DEFINER]
      │  فحص الهوية · الرتبة · الشيفت المفتوح · تحديد المعدل
      ▼
emp_ops.*
```

## لماذا نفس مشروع Supabase؟

لأن الموظف مسجَّل دخوله في مدعوم بالفعل. باستخدام عميل Supabase نفسه:

- **لا تسجيل دخول ثانٍ** ولا قاعدة مستخدمين موازية.
- **لا مفاتيح جديدة**، ولا حاجة لتمرير مفتاح خدمة إلى المتصفح.
- الهوية تصل إلى الخادم داخل JWT موقَّع من Supabase — لا يستطيع أحد انتحال
  زميله بتعديل حمولة الطلب.

العزل مضمون على مستوى **المخطط**: كل شيء في `emp_ops`، ولم يُمسّ أي جدول أو
دالة أو سياسة في `public` الخاص بمدعوم. الاعتماد الوحيد على الخارج هو مفتاح
أجنبي للقراءة على `auth.users(id)`.

## التركيب في مدعوم

**١) انسخ الملف** `sdk/mad3oom-activity-client.js` إلى مستودع مدعوم.

**٢) هيّئه مرة واحدة** عند تحميل التطبيق (بعد توفّر جلسة المستخدم):

```js
import { Mad3oomActivity } from '@/lib/mad3oom-activity-client';
import { supabase } from '@/lib/supabaseClient';

Mad3oomActivity.init({ supabase });
```

**٣) سجّل العمليات الحقيقية** في أماكنها:

```js
// عند فتح تذكرة
Mad3oomActivity.track('ticket_open', { entityType: 'ticket', entityId: ticket.id });

// عند إرسال رد
Mad3oomActivity.track('ticket_reply', { entityType: 'ticket', entityId: ticket.id });

// عند تغيير الحالة
Mad3oomActivity.track('ticket_status', {
  entityType: 'ticket', entityId: ticket.id,
  metadata: { from: oldStatus, to: newStatus }
});

// عند البحث (بدون نص البحث)
Mad3oomActivity.track('search', { metadata: { results: count } });
```

## الأنواع المتاحة

من جدول `emp_ops.activity_types` — إضافة نوع جديد = صف واحد، بلا نشر جديد:

| الكود | العملية | يمنح نشاطًا |
|---|---|---|
| `ticket_open` | فتح تذكرة | ✅ |
| `ticket_reply` | إرسال رد | ✅ |
| `ticket_status` | تغيير حالة | ✅ |
| `ticket_assign` | إسناد تذكرة | ✅ |
| `ticket_note` | ملاحظة داخلية | ✅ |
| `chat_reply` | رد على محادثة | ✅ |
| `search` | بحث | ✅ |
| `navigation` | تنقّل | ✅ |
| `tool_use` | استخدام أداة دعم | ✅ |
| `ui_interaction` | تفاعل واجهة | ✅ |
| `page_view` | عرض صفحة | ❌ يُسجَّل للتدقيق فقط |
| `page_focus` / `page_hidden` | تبديل التبويب | ❌ |

الأنواع غير المعروفة تُتجاهل بصمت على الخادم — لن تُسقط النداء ولن تُخزَّن
(اختبار ت٥).

## متى يُحتسب Active Time بالضبط؟

الـSDK يراقب `visibilityState` و`focus`/`blur`، ويرسل حالة الانخراط مع كل نبضة.
الخادم يحتسب فقط بينما يكون على الجهاز تبويب مدعوم **واحد على الأقل ظاهرًا وعليه
Focus**، مع تفاعل حقيقي داخل نافذة الخمول.

الانتقال إلى تبويب أو تطبيق آخر يوقف الاحتساب فورًا (نبضة خروج فورية عند `blur`)
بينما يستمر وقت الشيفت كما هو. لوحة العمليات ليست ضمن التطبيقات المؤهَّلة، فبدء
الشيفت وترك اللوحة مفتوحة لا يُنتج أي وقت نشاط.

## ماذا يحدث إن لم يبدأ الموظف شيفته؟

يُعيد الخادم `status: "no_session"` ولا يُحتسب أي شيء. العميل يبطئ إيقاعه
تلقائيًا. يمكن لمدعوم قراءة `activity.isOnShift` لعرض تنبيه لطيف:

```js
const activity = Mad3oomActivity.init({
  supabase,
  onStatus: (s) => {
    if (s?.status === 'no_session') showBanner('لم تبدأ شيفتك بعد — افتح لوحة العمليات لبدء العمل.');
  }
});
```

## ضمانات لن تنكسر

- إن تعطّل هذا النظام بالكامل، لا يتأثر شيء في مدعوم: كل استدعاءات الـSDK
  محاطة بمعالجة أخطاء، والفشل يؤدي إلى تراجع تدريجي فقط.
- إن عُدِّل ملف الـSDK في المتصفح، لا يستطيع زيادة وقت أي موظف: الخادم يرفض
  أي نشاط بلا شيفت مفتوح، ولا يقبل أي وقت من العميل، ويقصّ كل احتساب على
  نافذة الخمول.
- الأحداث لا تُخزَّن إلا لموظف مسجَّل ونشط وله شيفت مفتوح.

## نموذج البيانات المتبادَل

| يُرسَل | لا يُرسَل |
|---|---|
| هل تبويب مدعوم ظاهر وعليه Focus | أي شيء عن التبويبات أو التطبيقات الأخرى |
| نوع العملية من الكتالوج | نص أي رسالة أو رد |
| معرّف الكيان (رقم التذكرة) | محتوى التذكرة |
| عدّاد رقمي للتفاعلات | أي مفتاح من لوحة المفاتيح |
| ظهور التبويب وعدد التبويبات | لقطات شاشة أو حركة الفأرة |
| معرّف جهاز مجهول + اسم النظام | أي نشاط خارج صفحات مدعوم |
